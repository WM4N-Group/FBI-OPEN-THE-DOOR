# Protected curriculum v3 engineering evidence, 2026-11-15

**No learned full-task success is claimed here.** V2 ended0/64 for all four final models. This new design freezes a v1 task reference and trains a zero-initialized12D bounded joint residual, with explicit nonlearned static-load/balance and nominal low-crawl references. The nominal model controller's successes must not be credited to PPO.

- Final `*_preflight.json` fingerprints the actual source, reference checkpoint,384-input schema, exact zero initial residual, v1 first-ascent target parity, continuing-world teacher history alignment, original CPU/GPU fixed-action short integration, target bounds, arm target lock and forbidden-collision negative detection.
- Final `*_smoke.json`:2048 worlds, two finite PPO updates/262144 aggregate environment steps. The new residual actor output weights changed; arm targets did not. The first training-stage successes are **partial goals**, not complete climb or rail passage.
- `climb_settle2.json`, `down_crouch_easy.json`, `down_crawl_short_goal.json`, `climb_full_baseline.json` are **development-only**, from intermediate source revisions, explicitly marked and not a final benchmark. In particular, developmental static goals can pass while full style-qualified tasks or low movement remain unsuccessful. Original ascent preservation alone did not meet the new style. Do not pool these with final evaluation or present them as RL gains.
- Later development after balance feedback achieved64/64 on-box stance and64/64 upright-start crouch **with zero residual**, but the tried nominal low gait was not a validated moving skill. An analytical swing-load redistribution variant caused failures and was rejected; final baseline retains bounded stance preload, with a7cm/2cm nominal foot path and a wider, filtered learned moving residual. Curriculum gates/watchdogs must diagnose failure instead of manufacturing success.
- Partial on-box / low-pose states exist only at explicitly labeled curriculum resets. Full tests always start upright on floor. Test collision injection is an explicit negative reset and must fail. No rollout pose manipulation, weld, obstacle actuator, hardware control or perception-policy success is claimed.

Stage-goal and full-task reports are separate. The full acceptance gates retain v2's small-step, compact-pose, stability and physical requirements; down's time allowance is increased to60s to permit slow movement. Geometry difficulty is easier for preparatory stages and ramped only for full training, while final full heldout remains difficulty1. A stage gate, budget end or engineer preflight is not full-task qualification. See `docs/CURRICULUM_V3.md`.
