# 当前状态与证据边界

更新日期：2026-11-14。`0.1.0`是研究代码/迁移准备版，不是硬件发布版。

## 能做什么

- 已有冻结的12维腿策略接口；机械臂6轴和夹爪独立控制。
- 规则流程＋6D IK＋真实双指碰撞接触，沿把手圆弧下压、解锁、跟随门运动、松爪收臂和门洞通过。
- 简化物理门：无回关弹簧/铰链阻尼，保留把手弹簧和门锁约束。
- 残差PPO训练与阶段门禁，保留配置/哈希/CSV/checkpoint。
- 头部＋腕部RGB-D、无调试标记的分割数据训练、在线观察与特征输出。
- 离线限位/速度/反馈时效/坐标变换检查，以及不发硬件指令的dry-run。
- 保留原ROS2机械臂执行层，供有现场操作员的独立bring-up参考。

## 不能据此声称什么

- **不是可靠视觉闭环开门。** 主控制器明确拒绝视觉模式，在线相机结果不控制运动。
- **不是已训练的HRL任务管理器。** 高层训练为残差控制，阶段切换仍是规则。
- **不是真机自主开门软件。** 整机硬件transport、已标定夹爪力/反馈与底盘停止适配尚未实现。
- **不是标准PiPER兼容策略。** 冻结权重与资产对应旧Piper L。
- **不是完整锁舌物理模型。** 解锁是实际抓握/把手角度触发的简化约束解除。
- **不是普遍成功率。** 一条teacher视频和初始朝向门禁不覆盖真实门型、光照、摩擦、延迟、载荷和安全验收。

## 历史实验摘要（不是整理版回归结果）

- 原规则抓握基线：seed111完整演示20.9秒；少量初始姿态检查2/3完成，仍有失败。
- 原三组残差PPO：teacher-grasp阶段分别32/32通过；2026-11-13 15:29观测时正在press训练/评估，累计约44～45万环境步。不能据此声称完整开门或视觉成功。
- 无标记双相机模型：头部IoU0.8196、腕部0.5974；腕部可见中心误差P95约14.13 cm，未达可靠精细伺服条件。
- 旧阶段权重和数据未随源码提交；私有reference包只提供冻结底层与原模型依赖。

整理版的实际回归证据见`provenance/release_validation.json`。缺ROS/固定SDK的硬件层测试应记录为未执行，而不是通过。即使离线执行层测试通过，也不是实机接触验收。
