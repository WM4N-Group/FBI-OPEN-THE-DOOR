# 相机

已实现头部`head_rgbd`和J6/link6固定的`wrist_rgbd`。腕部位置/朝向来自模型近似，不是实测外参。标称相机内外参仅用于仿真数据生成，不能下发到真机。

- 全部debug site从传感RGB中关闭，包括TCP和handle_grasp标记。
- `capture(labels=False)`不返回语义mask；`DualCameraObserver`只从RGB预测mask，再用深度和相机位姿反投影。
- 在线前端按连通域、面积、预测置信度和合理深度范围接受/拒绝；不要在拒绝后静默用真值代替。
- 近距离夹爪遮挡、反光、深度空洞、模糊和时间不同步尚需实测/训练。
- 标准例子`configs/hand_eye.example.json`必须被实测标定检查拒绝。真实文件需要米制平移、右手旋转、明确父/子帧和标定证据。

原3072场景/80epoch无debug标记模型，512独立测试场景：头部IoU0.8196，腕部0.5974；可见表面中心误差P95分别4.39 cm与14.13 cm。不是抓取点误差，也不满足可靠精细伺服。早期含调试标记的结果不作为最终证据。

头部负责全局寻找与粗定位，腕部用于局部观察；是否抓稳仍需接触/夹爪与相对运动证据。当前模型、数据和运行输出属于私有产物，不随源码发布；需要按仿真说明训练或经授权转移。
