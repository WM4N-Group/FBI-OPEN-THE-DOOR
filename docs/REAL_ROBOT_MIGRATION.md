# 真机迁移：先辨识与检查，再接触

## 0. 当前不可直接做的事

本仓库没有实现/批准整机自主开门硬件transport，`doctor`会一直保留该阻断项。不要通过更改布尔值来假装接口已经完成，也不要把仿真`data.ctrl`、关节角数组或夹爪20 N直接发给SDK。

旧策略机器人是Piper L。现有硬件执行层的限位来自原项目的**标准PiPER**。二者并存是一个明确的迁移阻断项，不是兼容性承诺。更换模型/末端/关节映射后必须重做验证；底盘RL也未验收推门反力。

## 1. 只读核查（不使能、不自动复位）

现场记录，存入不提交的`configs/real_robot.local.json`与标定文件：

- Go2/机械臂/夹爪型号、固件、SDK版本、ROS版本、关节名称/顺序/正方向/单位。
- 逐轴实测反馈与URDF核对，特别是J6：旧仿真约±180°，标准硬件配置约±120°。
- 夹爪开度命令、反馈单位、限位、速度、可用力/电流接口、力限幅是否真的生效。**本仓库未实现通过SDK自动抓握。**
- 各轴电流/力矩观测能力及标定；不可默认仿真中PD+偏置力矩能原样部署。
- TCP：夹持接触区域相对法兰的变换。旧执行层的部分运动学以法兰为参考，不是手指中心。
- 两台相机序列号、内参、畸变、深度单位、近距离有效范围和时间戳。
- 实测`T_link6_wrist_camera_optical`；整机定位/关节反馈与图像的时间同步。
- 急停、通信中断、看门狗、轨迹取消、底盘停止和机械臂停止之间的职责。

## 2. 原机械臂执行层：单独隔离准备

`hardware/arm`保留原项目ROS2 Foxy接口及恢复状态机，来源和许可证见第三方声明。目录可放在机器人原有容器中使用。它不是新写的开门任务执行器。

- 运行环境：原项目验证组合为ROS2 Foxy/Python3.8、PiPER SDK0.6.2；本仓库未在当前真机重新验证。
- 固定SDK按原加载器装到`hardware/third_party/piper_sdk_runtime`（此目录被Git忽略），不要替换系统环境或其他运行中的SDK。
- CAN配置必须由现场操作员核查；不要让脚本自动down/up正在使用的CAN。
- `hardware/arm/run_executor.py`默认被动读取；明确的服务/键盘操作才申请接管、恢复和使能。它可能在明确请求后实际运动，必须先读源码并布置急停。
- 本次把默认手动速度比例降到5%，末端步进速度降到5 mm/s、关节步进速度降到5°/s，并取消执行层将轨迹速度固定为100%的行为。**这些是软件保守默认值，不是安全认证或经过真机验证的推荐上限。**
- 轨迹话题：`/follower/arm_controller/joint_trajectory`；反馈：`/follower/feedback/joint_states`。只允许一个发布者。
- 原执行层不提供本任务所需的已核验夹爪控制、抓稳判断或底盘接管接口。不得以“ROS话题能发出去”当作整机可开门。

离线测试，不会连接机器人：

```bash
python scripts/test_legacy_arm.py
```

依赖不齐时脚本明确列出缺项并返回77（未执行），不把ImportError或跳过当作通过。当前训练服务器缺ROS2消息/固定SDK，无法验证这组执行层测试；即便离线测试通过，也不是实际硬件验收。

## 3. 分级试验，逐项记录后才能升级

| 阶段 | 内容 | 不允许越过的边界 |
|---|---|---|
| A | 无硬件dry-run、模型/标定/单位检查 | 不发CAN/DDS运动指令 |
| B | 独立机械臂、自由空间小范围点动 | 底盘不运动，不接触门 |
| C | 固定测试台上的单独夹爪开合与可控假把手 | 先核验夹爪力、停止与反馈 |
| D | 机械臂压把手，底盘稳定静止且有人监督 | 验证限力、滑脱、接触超时和撤退 |
| E | 无回关器的推门，有限开角与安全撤退 | 先验证反力/底盘稳定性 |
| F | 释放、收臂、门洞通过 | 检查整机包络、门框碰撞与底盘独立停止 |

任何阶段出现模型不匹配、反馈过期、图像失效、力超限、滑脱、底盘倾斜或停止接口失效，都应停止升级。位置保持并非在所有情况下都安全，现场停止策略必须由实际硬件能力决定。

## 4. 后续需要补的硬件适配

- 已测量的模型/TCP/手眼标定及同步链。
- 夹爪命令、单位、力限幅、实际反馈、停机行为与双指/滑移估计。
- 与真机位置接口兼容的外层柔顺/导纳策略；不要假设SDK支持任意关节力矩控制。
- 从真实反馈更新的IK目标、碰撞检查、工作空间和关节速度限制。
- Go2状态/速度指令/接管/独立停止适配；模型匹配并完成接触试验前保持整机自动任务禁用。
- 在同样的传感输入与安全限制下，比较模型控制基线和残差RL，按真实成功率/力/碰撞/恢复表现决定是否引入RL。
