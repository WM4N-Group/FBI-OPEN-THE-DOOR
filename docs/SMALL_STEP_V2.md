# Small-step v2：登箱收拢站稳，先下蹲再小步钻杆

2026-11-15，响应用户对首轮视频的动作风格反馈。**实现训练约束并启动重训，不代表新动作已学成。** 此版本仍是直接微调12维腿actor；机械臂六轴目标始终保持home，以原限幅PD+bias执行，没有手臂动作输出或机械焊接。

## 与首轮不同

- `climb`：保留“靠近→上箱→站稳”的目标。慢速参考9–15cm/s，限制腿关节位置目标变化率6rad/s（保留登箱时必要的平衡纠正能力），惩罚摆腿水平距离、相对机身的前后/左右过伸、超高抬脚、落脚冲击和上箱后的继续移动。四脚实际支撑箱顶后，将前进参考置零，奖励收拢到紧凑站姿并稳定保持2s。目标置零不是硬制动，是否真的站稳仍由真实状态验收。
- `down`：规则阶段为**原地下蹲→低姿态小步穿越→完全过杆后恢复站稳**。阶段切换依赖实际机身高度、整机碰撞包络低于横杆至少12mm、至少3脚支撑、低速/低角速度和臂误差，连续达到0.30s才进入crawl；未满足前先平移超过18cm判失败。下蹲期间没有前进正奖励。crawl速度参考6.5–10cm/s，目标变化率1.2rad/s，惩罚大幅跨步和过高抬脚，不使用climb的跨越动作脚本。
- 这不是把动作直接缩小后就宣称会爬：目标限速是环境中的实际执行变换，**必须重新学习**。速度参考和时钟频率也改变了；复制actor对同一输入数值等价，不代表整个旧闭环行为不变。

## 奖励和验收

首轮有持续的箱顶/接触/姿态正奖励，可能让等待中间状态比尽快收尾更划算。v2去掉这些持续正奖励，改为：距离/高度的**有符号进展**、一次性阶段/支撑进展、稳定保持进度差、成功终奖，以及每步时间成本、腿部过伸/抬脚/落脚/滑移/速度成本。没有仅靠一直站在箱上或一直蹲低就不断获得固定正奖励的项。

下蹲加入对称两连杆近似得到的紧凑站姿**奖励先验**（腿长2×0.213m），climb上箱后也有home附近站姿成本。它只是reward，不向关节发送IK目标，不生成固定步态；12个腿动作仍由可训练actor输出。先验并非完整动力学模型或真机标定。

真实脚接触额外以2ms子步采集，只将地面/箱体且法向竖直分量>0.65的接触当成支撑，避免把踢箱侧面误计为落脚。摆腿水平距离按离地至落脚/当前摆动追踪；相对机身的前后/左右过伸、机身速度、脚接触力、目标变化率均记录。原有机械臂/机身撞地、撞箱/杆、非相邻自接触、跌倒、臂偏差、箱体滑移/倾覆、物理容量溢出等检查保持；没有删碰撞或放宽这些原门禁。

除原任务条件外，成功还需符合风格约束：

| 指标 | climb | down |
|---|---:|---:|
| 最大单次摆腿水平距离 | ≤23cm | ≤14cm |
| 每脚相对home足位的前后偏差峰值 | ≤21cm | ≤16cm |
| 每脚相对home足位的左右偏差峰值 | ≤10cm | ≤8.5cm |
| 机身水平速度峰值 | ≤0.25m/s | ≤0.16m/s |
| 收尾站稳持续时间 | 2s | 1s |
| episode时间预算 | 35s | 45s |

另有更宽的过伸/摆腿中止线防止严重异常；不满足成功风格条件的回合不能因为“已到另一边”就算合格。数值是**本轮仿真开发约束，不是安全认证或真机推荐值**。重新评估/看视频后才能判断风格是否实际符合用户要求。


开发阶段比较1.8/3/4/6rad/s登箱目标slew：低slew更易在旧策略适配初期触发物理失败，高slew更多暴露原大跨步风格失败。因此最终保留6rad/s的平衡纠正范围，以足位/摆腿/速度约束学习小步，而不把所有关节一律过度放慢。旧actor加新约束的短试并未合格；预检通过不等于任务成功。

## 初始化、版本与训练

- schema：`leg-skills/small-step-v2`，观测360维：原320维的排列保留，新增40维记录阶段、下蹲保持、实际限速后的目标、足位/接触和摆腿状态。原始60×5历史输入中命令/时钟按新任务阶段构造，不能声称输入语义完全不变。
- warm start：climb从首轮seed600、down从seed701的最终actor复制，新增输入列置零。两个新种子分别从同一个对应任务actor初始化；重新初始化critic、优化器、探索噪声，**不恢复旧优化器，也不是原训练原封不动继续跑**。旧模型只读且校验SHA256。
- 两张A800，climb800/801各2048环境，down900/901各2048环境；每组新增2亿聚合环境步，合计8亿。horizon64、gamma0.997、GAE0.97。源代码/运行目录/输出与v1隔离；开发pilot不等于正式技能成功率。
- 继承首轮箱高、尺寸、质量、摩擦、初始偏差随机化；登箱仍是大于原推箱的自由承重箱，而非原40×50cm/2kg小轻箱。down是从横杆下通过，不是下台阶。
- 当前仍使用特权几何与真实模拟接触，**不是视觉、真机或共享世界长序技能链**。阶段管理是规则，不是学习型HRL管理器。

首轮最终测试已用于选择warm-start和本轮开发，不再当作本轮独立证据。v2监控和最终评估使用新的域种子，同时报告完整成功、phase失败、风格指标、超时和物理失败，不只挑成功视频。定期保存最新模型与监控集最优候选；监控最优不代表独立最终最佳。

## 复现

新建独立runtime并校验授权原资产；builder/物理后端与首轮相同，不更改原正在运行的源码。完整首轮后端限制见 `LEG_SKILLS.md`。

```bash
python -m fbi_door.leg_skills.validate_style \
  --runtime /absolute/path/to/new-runtime --task down \
  --warm-start /absolute/path/to/trusted-v1-down-policy.pt \
  --warm-start-sha256 SHA256 --output /absolute/path/to/new-preflight.json
CUDA_VISIBLE_DEVICES=1 python -m fbi_door.leg_skills.train_style \
  --runtime /absolute/path/to/new-runtime --task down --seed 900 \
  --warm-start /absolute/path/to/trusted-v1-down-policy.pt \
  --warm-start-sha256 SHA256 --envs 2048 --horizon 64 --steps 200000000 \
  --output /absolute/path/to/new-run
```

已存在的输出目录拒绝覆盖。预检包括actor复制误差、CPU/GPU同动作短积分、目标限速、真实脚支撑检测、碰撞负例和未下蹲提前移动负例；负例是明确的测试reset，不是训练中的搬运机器人/箱体。权重、视频、私有资产和服务器路径不进入Git。训练写本地缓冲，持续同步共享存储；保留所有旧实验。
