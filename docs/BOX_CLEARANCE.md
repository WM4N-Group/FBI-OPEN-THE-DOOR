# 推箱碰撞修订：clearance_v2

2026-11-14。此版本响应视频中的碰撞风险，**默认替代旧v1候选**。只验证仿真，未运行硬件。

## 旧版本遗漏了什么

原“8/8成功”检查箱体前移、机械臂接触、机身/腿撞箱、锁臂和收臂，但没有把机械臂—机身自碰纳入成功判据。对旧视频相同8个初态（71000～71007）重新审计：

- 检查的碰撞代理出现4.13～4.35 mm负间隙；自接触法向力峰值50.60～54.11 N。
- 旧IK在原地快速改变末端姿态，且直接用关节插值收臂，夹爪/腕部会从机身前部扫过。
- 旧数据和权重保留，不把完成推箱等同于路径安全，不继续将v1当成部署候选。

首次10 Hz粗查约1.7 mm负间隙；提高为50 Hz几何检查后发现更深的约4.3 mm穿入，二者采样口径不同。不是修图或只降低播放速度。

## 控制上的改动

流程为：

`approach → settle → reach → touch → push → stop → retreat → withdraw_settle → retract → success`

1. **提前减速和停稳。** 接近速度上限从原0.22 m/s降到0.12 m/s，用停止距离提前制动；纵向速度指令每秒变化不超过0.06 m/s²（仅仿真候选）。
2. **先伸到机身前上方，再下降。** 对高位和箱前接触位姿求全姿态IK，从多个初值筛选可行分支。夹爪闭合方向改为横向，腕部相机朝上侧，减少向机身前部扫掠；目标TCP高度0.34 m，工具轴向下倾30°。不是只插值位置而瞬时跳变姿态。
3. **检查关节路径。** 检查直连路径，必要时用最多700次采样的RRT回退；无路径就失败，不放松间隙继续。执行时对实际关节状态至下一位置目标按不超过0.01 rad间隔重新离散检查。关节目标速度上限0.30 rad/s（原伸臂0.80、收臂0.60）。
4. **缓慢建立接触。** 机械臂目标先锁定，以0.025 m/s底盘指令靠近；正接触累计达到0.20 s后才进入推箱。推箱名义速度0.075 m/s，残差后上限0.095 m/s，并渐变加减速。
5. **先卸力退离，再收臂。** 推完停稳，保持臂姿后退至少0.20 m；要求指垫—箱体间隙至少0.08 m，接触力低于0.15 N持续至少0.30 s。再次停稳后，反向跟随已检查伸臂路径；不会贴着箱面直接折臂。反向路径执行仍重新检查，不假设缓存路径天然一直安全。

高层仍为6维残差；IK位置偏置在`reach`首次策略观测时锁存，限幅为±5/10/10 mm，之后不追逐变化的策略目标。锁臂、接触、卸力、后退和收臂阶段屏蔽机械臂残差。

原12维冻结腿策略、300维历史输入、动作映射、PD力矩上限、机器人碰撞代理、2 kg自由箱体和摩擦参数均保留。没有关掉碰撞、删掉机身外形、给箱体加执行器/焊接，或直接改箱体位置。只改高层目标与检查；仍是特权几何、规则阶段管理、IK和残差PPO，**不是视觉闭环或学习型HRL**。

## 检查范围与局限

- 保留模型中的collision geoms，不用视觉网格代替或假装真实外壳完全准确。自碰距离检查独立于MuJoCo碰撞bitmask，避免“仿真过滤掉接触就等于安全”。同体及树距离≤2的机械相邻体被明确排除；**没有证明这些排除覆盖真实机构的全部风险**。
- 规划候选自碰代理间隙要求25 mm；最终回合验收要求被检查的实际间隙至少20 mm，机身/腿—箱体至少160 mm，非指垫臂段—箱体至少15 mm，机械臂—地面至少70 mm。
- 实际几何以50 Hz从状态重新FK采样；接触力以2 ms物理子步采集，越限的episode停止在下一20 ms控制检查。关节路径是离散检查，**不是连续碰撞或动力学安全证明**。
- 非指垫撞箱、自接触、基座失稳、箱体倾倒/侧偏、模型接触力超过25 N、路径或阶段超时等触发停止/失败。25 N只是此仿真任务的停止阈值，不是核验过的硬件安全力。
- 没有建模背后障碍、线缆、人或标定误差，也没有测量真实相机/夹爪外壳；真机后退空间必须另行感知和确认。沿用[真机迁移阻断项](REAL_ROBOT_MIGRATION.md)，不使能CAN/DDS。

## 同初态回归对照

两者均为零高层残差的规则/IK基线，相同箱体物理、冻结腿策略、8个reset种子。v1只加观测审计，不应用v2干预。

| 指标 | 旧v1 | clearance_v2 |
|---|---:|---:|
| 完成推箱与收臂 | 8/8，**不含自碰门禁** | 8/8，含新门禁 |
| 平均耗时 | 16.10 s | 40.28 s |
| 箱体前移 | 0.532～0.539 m | 0.540～0.542 m |
| 最小被检查的自碰代理间隙 | −4.35～−4.13 mm | 30.18～30.25 mm |
| 自接触峰值 | 50.60～54.11 N | 0 N |
| 机身/腿—箱体最小代理间隙 | 0.188～0.202 m | 0.224～0.233 m |
| 非指垫撞箱接触峰值 | 0 N | 0 N |
| 末端—箱体接触峰值 | 12.20～16.78 N | 13.21～14.14 N |

推箱所需接触仍存在。**不能说所有受力都变小了**：末端—箱体峰值均值约13.43→13.53 N，主要改进是消除这组回归里的自碰并拉开收臂间隙，代价是明显变慢。数值都是仿真诊断，不是真实力传感器读数。

这些种子用于开发/回归，包括调试过的71000，不是盲测总体成功率。没有证明随机质量、摩擦、复杂障碍、视觉或硬件泛化。原始数据在`provenance/box_clearance_20261114/`；视频为v2规则＋IK基线，1倍速，不能冒充训练完成的新PPO。

标准库测试64项通过；带资产回归另验证Gym接口、确定性reset、旧穿入姿态被拒绝、锁臂掩码、卸力退离及完整收臂。512步smoke验证参数改变、原子保存与重载动作一致（SB3 `n_updates=10`计数）。

## 使用与训练

独立运行目录与资产生成见[推箱说明](BOX_PUSH.md)。默认CLI控制器已改为v2；保留`--controller legacy`仅用于复查历史实验。

```bash
export FBI_DOOR_RUNTIME=/absolute/path/to/new-box-clearance-runtime
export MUJOCO_GL=egl OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
python scripts/test_box_clearance_sim.py
python -m fbi_door.sim.evaluate_box --controller clearance_v2 --count 8 --seed 71000 \
  --output "$FBI_DOOR_RUNTIME/reports/v2.json" --video "$FBI_DOOR_RUNTIME/reports/v2.mp4"
python -m fbi_door.sim.train_box --controller clearance_v2 --run-name v2_s200 \
  --seed 200 --envs 6 --device cuda:0 --nominal-steps 200000 --perturbed-steps 800000
```

新的四种子为GPU0：200/201、GPU1：202/203，各6环境，名义各100万步；阶段门禁及有限重试保留。独立源码部署和系统盘buffer＋共享镜像，不覆盖门任务及v1实验。

**v2的阶段/观测契约与v1不同，因此重新初始化高层PPO，不直接加载v1高层checkpoint。** 原冻结12维腿权重仍复用。先验证新训练发生梯度更新，再归档旧v1运行，保留其最后checkpoint、哈希和退出原因，不将中止标成“训练完成”。训练尚未完成时，不声称新PPO优于新IK基线。
