# V4：少量下蹲再走、登箱后恢复水平正常站姿

2026-11-16，按用户对v3视频的反馈继续训练。**修改控制/奖励并开训，不等于完整技能已学成。** v1/v2/v3代码、资产、权重和原始结果全部保留。

## 新要求与实现

### Down：只降低必要高度，然后有效小步走

- 不再把身体压到固定深蹲高度。用当前整机碰撞包络（包含锁臂和相机）相对底座的最高点偏移，计算最高可通过姿态：`min(normal_height, rail_clearance - envelope_offset - 0.015m)`。目标平滑变化，原物理碰撞/倾倒/停机检查不放宽。
- `normal_height`在本模型取0.30m；落到0.135m以下的理论目标**不能被宣称可行**。实现保留下限避免无限下蹲，实际净空仍不满足就不能通过准备门禁，碰撞则物理停止。某些很低的杆配合固定锁臂仍可能不可行；不会改小机器人外形、偷偷升高杆或减去机械臂来制造结果。
- 下蹲准备要求实际高度在所需高度附近±15mm、整机顶部余量≥12mm、3+脚支撑且低速，持续0.30s。不是越低越好；深于必要高度会受罚。准备子目标仍需保持1s。
- v3移动时只保留10%的旧步态，且叠加静态支撑参考，难以有效抬脚。v4去掉手写脚摆动，恢复冻结v1 RL步态在浅蹲参考周围的有效输出；基准幅度随实测速度在27.5%–55%调节，渐入0.8s。**开发中100%幅度能前进但停步时容易摔倒，因此没有将它当成可部署结果。** 继续训练的12维关节残差负责修正，不声称从零学出步态。
- 减速/停止时锁存实际已执行腿目标并在1s内平滑交给静态支撑，避免从动态跨步突然切换到静止姿态。短距离移动目标为25cm，位置容差2cm；它仍是明确标记的部分目标，不等于穿杆。
- 完整任务仍须先真实下蹲，再从杆下内部通过，整机尾部离开后恢复正常高度并站稳；不能侧绕、压杆或用低姿态reset代替完整起步。

### Climb：上箱先停稳，再恢复水平正常高度

内部规则阶段为：`ascent → gather/stop → normal upright recovery`。这不是学习型高层管理器。

- 上箱前保留原冻结v1任务actor的历史输入/动作映射，加有界关节残差；不在登箱开始同时大改速度、时钟和全局关节slew。
- 四脚真的支撑箱面后先保留v3已能收稳的落脚控制。满足低速度/低角速度并保持0.15s后，锁存当前已执行腿目标，平滑交给新的正常站姿控制，不在尚未收稳时强行抬高。
- **正常站立目标**：底座相对箱顶高度0.30m±0.02m，roll和pitch各≤3°，紧凑足位并保持2s。不能仅仅停在箱上但低头/侧倾就算正常。
- 高度参考以1.5cm/s渐变，加入限幅的高度/roll/pitch积分和姿态阻尼，静力参考网格上限从0.31m扩到0.35m以补偿PD负载下沉。积分只在控制器真正生效时累积，避免登箱途中姿态误差“积分蓄积”导致切换冲击。
- 姿态恢复奖励包含高度和横滚/俯仰误差下降；达标保持进度**封顶**，满2s后继续站着不再不断领取“进度”奖励，完整风格通过有单独终奖。

## 真正在训练什么

仍是**冻结v1参考＋显式姿态控制基线＋可训练12维腿关节残差**，不是上层6维速度/TCP残差，也不是再次全量训练v1 actor。机械臂六轴目标保持home，用原限幅PD+bias，不是机械锁死。残差tanh/幅度边界、原关节/力矩/碰撞/自碰/失稳停止规则保留。

从v3已经通过子阶段的快照继续，而不是继承最终失败的整段动作：

| 新种子 | 起始残差actor | 来源步数 |
|---|---|---:|
| climb1200 | v3 climb1020 `policy_passed_settle` | 2,097,152 |
| climb1201 | v3 climb1021 `policy_passed_settle` | 2,097,152 |
| down1300 | v3 down1120 `policy_passed_crouch` | 2,097,152 |
| down1301 | v3 down1121 `policy_passed_crouch` | 2,097,152 |

SHA256先校验，再加载。输入384→392维，新增实际roll/pitch/支撑相对高度、当前目标高度、3个限幅积分和净空信息；新增列初始化0，复制actor对同一原输入的数值误差经过测试。**闭环基线/阶段含义已变，不宣称行为与v3完全相同。** critic、优化器、探索噪声重新初始化，不恢复旧优化器。状态记录新的高度/roll/pitch/净空指标。

## 训练、门禁与结果解释

两张A800分别跑climb1200/1201、down1300/1301，各2048环境，每组最多新增1.5亿聚合环境步，总上限6亿，不保证跑满或收敛。

- 子阶段仍用≥75%的32例门禁升级；climb为箱上正常恢复→完整，down为浅蹲→短距离低姿态移动→完整。子阶段reset目标与完整任务分开记录。
- 子阶段上限约2400万步；完整阶段约6000万步如果连正常任务目标或严格风格目标都没有进展则保存并停止该组。阈值在评估门禁处检查，存在向量rollout取整/门禁间隔超出。
- 每400万步监控，独立最终报告另用新种子。完整训练几何难度从0.4逐步到1，完整heldout始终难度1；准备阶段的较易几何分布不冒充泛化成功。
- 新增`policy_best_normal_goal.pt`与对应报告，**正常任务目标候选不是严格小步风格的完整成功**。原严格全程步幅/撑腿/速度条件保留；同时记录完整成功数和正常任务目标数，不能混用。完整down恢复高度容差仍为2.5cm，但围绕新的正常高度0.30m，不再让控制目标与验收中心互相矛盾。
- Down仍允许60s，climb35s；步幅/速度等旧风格限制不因“更正常”或“能走了”而放宽。

当前使用特权几何、同一Go2＋Piper L及固定锁臂形态；没有视觉策略、真机或共享世界技能链。登箱仍是大于原2kg小推箱的承重自由箱体，不能推断小箱承重或现实安全。姿态角和15mm净空是开发指标，不是安全认证。
